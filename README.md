# 多多性別大猜謎（朋友版）

給朋友投票猜多多是男生還是女生，並寫下理由的小網站。和家人版功能相同，但沒有抽獎。

- `index.html`：投票頁（分享這個連結給朋友）
- `results.html`：主辦人看票數、理由；揭曉時選擇性別，列出猜對的人
- `apps-script/Code.gs`：Google Apps Script 後端，票存在 Google 試算表
- `config.js`：填入 Apps Script 網址

## 設定後端（約 3 分鐘，只需一次）

請用**新的**試算表，朋友的票才不會和家人的混在一起。

1. 建立一個新的 Google 試算表（例如「多多投票－朋友」）。
2. 選單「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 的內容整個貼上，存檔。
3. 等幾分鐘，在函式選單選 `doGet` 按「執行」並授權（避免 OAuth 尚未建立的錯誤）。
4. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分 **我**；誰可以存取 **所有人**。
5. 複製結尾是 `/exec` 的網址，貼到 `config.js` 的 `VOTE_API_URL`。

之後修改 `Code.gs` 時，用「部署 → 管理部署作業 → 編輯 → 新版本」，網址才不會變。
